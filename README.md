# 🚀 从零基础到企业级：RAG · Agent · Prompt · LangChain/LangGraph 全栈 AI 学习体系

> **目标**：让零基础小白在 12-16 周内，全面、多维度、成体系地掌握高召回率、高准确率的企业级 AI 应用架构。

---

## 📖 这是什么？

一套**螺旋式递进**的全栈 AI 工程学习体系，覆盖 5 大核心范式：

| 范式 | 核心能力 | 难度 |
|------|---------|------|
| **Prompt 工程** | 设计、测试、优化 LLM 提示词 | ⭐⭐ |
| **RAG（检索增强生成）** | 基于外部知识库的精准问答 | ⭐⭐⭐ |
| **Agent（智能体）** | 自主规划、工具调用、多步推理 | ⭐⭐⭐⭐ |
| **LangChain/LCEL** | 标准化 AI 应用开发框架 | ⭐⭐⭐ |
| **LangGraph** | 企业级 Agent 工作流编排 | ⭐⭐⭐⭐⭐ |

## 📐 设计哲学

### 调优金字塔（逐层递进，绝不跳级）

```
        ┌──────────────┐
        │   预训练      │  $50万, 90天
        ├──────────────┤
        │   Fine-tuning │  $500, 2周
        ├──────────────┤
        │     RAG       │  $100, 3天
        ├──────────────┤
        │   Few-shot    │  $5, 半天
        ├──────────────┤
        │ Prompt 工程   │  $0, 数分钟
        └──────────────┘
```

> 💡 **黄金法则**：80% 的应用问题可通过 Prompt 工程 + RAG 解决，15% 需要 Fine-tuning，仅 5% 需要预训练。

### 每个阶段的五要素

1. **📚 概念** — 理论、架构图、原理解析
2. **💻 代码** — 可直接运行的生产级实现
3. **⚠️ 坑点** — 该阶段真实失败模式 + 根因分析
4. **🔧 解决方案** — 每个坑点的修复代码和最佳实践
5. **✅ 检验点** — 自测练习，验证掌握程度

### 坑点随阶段演进

同一概念在不同阶段有不同表现——**"幻觉"** 在三个阶段的三种形态：

| 阶段 | 幻觉表现 | 解决策略 |
|------|---------|---------|
| Prompt 工程 | 自信过头地输出错误信息 | 事实核查 + RAG 兜底 |
| Naive RAG | 无视检索内容，使用预训练知识 | 强制溯源 Prompt + 忠实度评估 |
| Agent | 发明不存在的工具名和参数 | 工具名校验 + JSON Schema 约束 |
