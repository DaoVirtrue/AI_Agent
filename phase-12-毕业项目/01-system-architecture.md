## 4. 数据流图

```
用户请求
  │
  ├─→ [API Gateway] 认证 + 限流
  │     │
  │     ├─→ [Security L1] 输入扫描 (注入检测)
  │     │     │
  │     │     ├─→ 阻止? → 返回安全拒绝
  │     │     └─→ 通过
  │     │           │
  │     │           ├─→ [AI Router] 意图识别 → 技能路由
  │     │           │     │
  │     │           │     ├─→ QA? → RAG Pipeline
  │     │           │     │         │
  │     │           │     │         ├─→ [Cache L1-L3] 检查缓存
  │     │           │     │         │     ├─→ 命中? → 返回缓存结果
  │     │           │     │         │     └─→ 未命中
  │     │           │     │         │           │
  │     │           │     │         │           ├─→ [Query Rewrite] 重写查询
  │     │           │     │         │           ├─→ [Vector Search] 检索
  │     │           │     │         │           ├─→ [Re-rank] 重排序
  │     │           │     │         │           ├─→ [LLM Generate] 生成
  │     │           │     │         │           └─→ [Cache L4] 存入缓存
  │     │           │     │         │
  │     │           │     │         └─→ 其他技能? → Skill Executor
  │     │           │     │
  │     │           │     └─→ [Security L2] 输出扫描 (PII/毒性)
  │     │           │           │
  │     │           │           ├─→ [Security L4] 内容策略
  │     │           │           └─→ 返回用户
  │     │           │
  │     │           └─→ [Evaluation Engine] 异步评估 (记录得分)
  │     │           └─→ [Audit Log] 记录审计事件
  │     │
  │     └─→ [Metrics] 更新Prometheus指标
  │
  └─→ [Response] 返回给用户
```

## 6. 技术栈

| 组件 | 技术选型 |
|------|---------|
| API框架 | FastAPI (Python 3.10+) |
| LLM Orchestration | LangGraph |
| 向量数据库 | Milvus / ChromaDB |
| 缓存 | Redis (4级: 内存 + Redis + 语义 + 提示缓存) |
| 数据库 | PostgreSQL (元数据 + 审计日志) |
| 消息队列 | RabbitMQ (异步任务) |
| 监控 | Prometheus + Grafana |
| 追踪 | LangSmith / OpenTelemetry |
| 容器化 | Docker + Kubernetes |
| CI/CD | GitHub Actions |
