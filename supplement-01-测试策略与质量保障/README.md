```
           ┌──────────────┐
           │  负载测试     │  ← 1次/版本

          ┌┴──────────────┴┐
          │  E2E 管道测试  │  ← 每次部署前
          │  属性测试      │

        │   (MockLLM/Mock)   │
        └────────────────────┘
```

## 质量门禁

```yaml
合并到 main 分支必须满足：
  - 单元测试通过率: 100%
  - Prompt 回归: ≥ 95% 基线
  - 检索 Hit Rate: ≥ 0.85
  - 回答 Faithfulness: ≥ 0.90
  - 幻觉率: ≤ 5%
```
