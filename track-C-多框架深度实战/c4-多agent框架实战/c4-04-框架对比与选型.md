## 一、框架定位速览

```
                    结构化程度
                         ↑
                    MetaGPT │
                    (SOP)   │   LangGraph
                            │   (可编程图)
                    CrewAI  │
                 (角色+任务) │
                            │
                    AutoGen │
                   (对话)    │
                         └──────────→ 灵活性
```

| 框架 | 一句话定位 | 设计哲学 | 创建者 |
|------|-----------|----------|--------|
| **CrewAI** | 角色驱动的团队协作 | Role → Task → Crew | CrewAI Inc. |
| **AutoGen** | 对话驱动的多 Agent 对话 | ConversableAgent + Chat | Microsoft |
| **MetaGPT** | SOP 驱动的软件公司模拟 | Role + Action + SOP | 深度赋智 |
| **LangGraph** | 可控的有状态 Agent 图 | StateGraph + Node + Edge | LangChain |

## 二、核心概念对比

| 概念 | CrewAI | AutoGen | MetaGPT | LangGraph |
|------|--------|---------|---------|-----------|
| **Agent 定义** | Agent(role, goal, backstory) | ConversableAgent(name, system_message) | Role(name, profile, goal) | Node (任意函数) |
| **任务定义** | Task(description, expected_output) | 无独立任务概念（对话即任务） | Action (execute) | 无（在 Node 中实现） |
| **编排方式** | sequential / hierarchical | 对话流转 (GroupChat) | SOP Pipeline | StateGraph (DAG) |
| **通信方式** | 隐式（Task context 传递） | 显式消息 (send/receive) | Message 对象 | State 字典 |
| **工具集成** | BaseTool 继承 | register_function() | Action 子类 | tool-calling / Node |
| **人机协同** | human_input=True | UserProxyAgent(human_input_mode) | 间接支持 | interrupt / Command |
| **结构化输出** | Task expected_output | 无强制 | Templates (PRD/Design/Code) | 自定义（Pydantic） |

## 五、代码量对比（同一任务）

### 任务：三个 Agent 协作研究并撰写一篇技术报告

**CrewAI (约 30 行)**

```python
from crewai import Agent, Task, Crew, Process

researcher = Agent(role="研究员", goal="研究课题", backstory="...")
writer = Agent(role="撰写人", goal="撰写报告", backstory="...")
reviewer = Agent(role="审核员", goal="审核报告", backstory="...")

task1 = Task(description="研究RAG技术...", agent=researcher)
task2 = Task(description="撰写报告...", agent=writer, context=[task1])
task3 = Task(description="审核报告...", agent=reviewer, context=[task2])

crew = Crew(agents=[researcher, writer, reviewer],
            tasks=[task1, task2, task3], process=Process.sequential)
result = crew.kickoff()
```

**AutoGen (约 60 行)**

```python
from autogen import ConversableAgent, GroupChat, GroupChatManager

researcher = ConversableAgent(name="研究员", system_message="...", llm_config=...)
writer = ConversableAgent(name="撰写人", system_message="...", llm_config=...)
reviewer = ConversableAgent(name="审核员", system_message="...", llm_config=...)

group_chat = GroupChat(agents=[researcher, writer, reviewer],
                        messages=[], max_round=10)
manager = GroupChatManager(groupchat=group_chat, llm_config=...)

user = ConversableAgent(name="用户", ...)
user.initiate_chat(manager, message="请研究RAG技术并撰写报告")
```

**LangGraph (约 120 行)**

```python
from langgraph.graph import StateGraph, END
from typing import TypedDict, Annotated, List
import operator

class State(TypedDict):
    messages: Annotated[List, operator.add]
    research: str
    draft: str
    review: str

def researcher_node(state): ...

builder = StateGraph(State)
builder.add_node("researcher", researcher_node)

builder.add_edge("writer", "reviewer")
builder.add_conditional_edges("reviewer", decide_next, {...})
```

## 六、选型决策框架

### 决策树

```
你的任务特点是什么？
  │
  ├── "从需求到代码的完整项目生成"
  │   └── → MetaGPT（SOP 最适合）
  │
  ├── "多个专家角色协作完成一个分析/写作任务"
  │   ├── 流程固定 → CrewAI（简单直接）
  │   └── 需要自由讨论 → AutoGen GroupChat
  │
  ├── "多轮对话式客服/助手"
  │   └── → AutoGen（对话驱动最自然）
  │
  ├── "复杂的生产级 Agent 应用（条件分支/循环/持久化）"
  │   └── → LangGraph（唯一支持全特性的选择）
  │
  ├── "需要强人机协同（Human-in-the-Loop）"
  │   └── → AutoGen 或 LangGraph
  │
  ├── "快速原型验证"
  │   └── → CrewAI（15 行代码搞定）
  │
  └── "需要与 LangChain 生态深度集成"
      └── → LangGraph（与 LangChain 无缝衔接）
```

### 场景-框架映射表

| 如果你要做... | 首选 | 备选 | 原因 |
|-------------|------|------|------|

| 代码项目生成 | MetaGPT | CrewAI | SOP 驱动代码输出 |

## 九、总结建议

| 你的情况 | 推荐 |
|----------|------|
| 刚接触多 Agent，想快速体验 | **CrewAI** |
| 需要构建生产级 Agent 应用 | **LangGraph** |
| 做对话式 Agent/客服 | **AutoGen** |
| 从零生成项目代码 | **MetaGPT** |
| 团队有强工程能力，需要最大灵活性 | **LangGraph** |
| 团队需要快速交付，灵活性不是首要 | **CrewAI** |
| 需要人机协同（审核/确认） | **AutoGen** 或 **LangGraph** |

**2026 年趋势**：LangGraph 正在成为企业级 Agent 的事实标准，CrewAI 在快速原型场景中表现优异。两者不是替代关系，而是互补关系。
