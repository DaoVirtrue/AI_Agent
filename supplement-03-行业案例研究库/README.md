# Supplement 03：行业案例研究库

> **定位**：从真实（或高度仿真的）行业案例中学习 RAG 系统的架构决策、踩坑经验和最佳实践
> **每个案例**：业务背景 → 技术架构 → 关键决策 → 数据管道 → 准确率优化 → 生产指标 → 踩坑记录 → 经验教训

---

## 案例索引

| 编号 | 行业 | 核心挑战 | 技术亮点 |
|------|------|----------|----------|
| s3-01 | 医疗 | HIPAA/PIPL 隐私 + 99%+ 准确率 | 精确引用到段落、人机双审 |
| s3-02 | 法律 | 多法域知识库 + 零容忍幻觉 | 法条级索引、逐句引用 |
| s3-03 | 电商 | 多模态 + 促销100倍流量 | 图片搜索+文本融合、弹性伸缩 |
| s3-04 | 金融 | 合规审查 + 数据隔离 | 审计追踪、租户级向量隔离 |
| s3-05 | 客服 | 多租户 SaaS + 持续更新 | 意图路由、知识闭环、满意度联动 |

---

## 学习每个案例时的关注点

1. **为什么这样设计架构？**
2. **他们踩了什么坑？**
3. **哪些是可以复用的模式？**
4. **什么条件下应该做出不同的选择？**
5. **准确率到底怎么优化的？**
