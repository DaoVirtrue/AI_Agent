## 二、供应商评估维度详解

### 2.1 推理质量

```
评估方法：
1. 用标准 Benchmark 对比（MMLU, HumanEval, C-Eval）
2. 用你自己的 100 个真实问题做盲测
3. 由 3 位内部专家评分
4. 关注：回答准确性、逻辑性、引用的准确性、幻觉率

关键发现：
- 英文推理：Claude Sonnet 4 ≈ GPT-4o > Gemini 2.5 Pro > 其他
- 中文推理：DeepSeek-V3 ≈ Qwen-Max > GPT-4o > 其他
- 代码生成：Claude Sonnet 4 ≈ GPT-4o > DeepSeek-V3 > 其他
- 长文本处理：Gemini 2.5 Pro (1M context) 独树一帜
```

### 2.2 稳定性与可靠性

```
评估维度：
- API 可用性（SLA）
- 延迟抖动（P99 vs P50）
- 限流策略
- 错误率
- 响应时间波动

2026 年观察：
- OpenAI: 最稳定（但高峰时段偶尔降级）
- Anthropic: 较稳定（容量有时不足）
- Google: 改善中（历史上稳定性一般）
- DeepSeek: 偶尔过载（免费用户多）
- Qwen: 国内稳定，海外访问受限
```

### 2.3 数据合规

```
关键问题：
- 数据存储在哪里？
- API 调用数据是否被用于训练？
- 是否提供数据驻留选项？
- 是否有 SOC 2 / ISO 27001 认证？
- 是否支持私有化部署？

合规矩阵：
| 供应商 | API数据用于训练 | 私有化部署 | 中国数据合规 |
|--------|---------------|-----------|------------|
| OpenAI | API不训练（企业版） | 不支持 | 需跨境评估 |
| Anthropic | API不训练（默认） | 不支持 | 需跨境评估 |
| Google | API不训练（默认） | 不支持 | 需跨境评估 |
| Qwen | 不训练 | 支持（开源） | 完全合规 |
| DeepSeek | 需核实 | 支持（开源） | 完全合规 |
```

### 3.3 Prompt 可移植性

```python
# 不好的做法：供应商特定的 prompt 格式
prompt = """你是一个助手。{context}

Human: {question}
Assistant:"""

# 好的做法：标准化 prompt 模板
from langchain_core.prompts import ChatPromptTemplate

prompt = ChatPromptTemplate.from_messages([
    ("system", "你是一个助手。\n\n上下文：{context}"),
    ("human", "{question}"),
])
# 框架自动处理不同供应商的消息格式转换
```

## 四、多供应商路由策略

### 4.1 智能路由决策树

```python
def route_llm_request(query: str, user_tier: str, budget_left: float):
    """
    根据多个因素动态选择 LLM 供应商。
    """
    # 1. 简单问题 → 便宜模型
    if is_simple_query(query):
        return ("openai", "gpt-4o-mini")

    # 2. 代码任务 → Sonnet 4
    if is_code_task(query):
        return ("anthropic", "claude-sonnet-4-20250514")

    # 3. 中文深度推理 → DeepSeek/Qwen
    if is_chinese() and is_complex_query(query):
        if budget_left > 0.001:
            return ("deepseek", "deepseek-v3")

    # 4. 长文档(>100K tokens) → Gemini
    if estimated_tokens(query) > 100_000:
        return ("google", "gemini-2.5-pro")

    # 5. 默认 → GPT-4o
    return ("openai", "gpt-4o")
```

## 五、供应商评估 RFP 模板

```yaml
评估检查清单：

1. 技术能力:
   - [ ] 提供模型的技术规格（参数量、上下文长度、支持语言）
   - [ ] 提供标准 Benchmark 结果（MMLU, HumanEval, C-Eval）
   - [ ] 提供微调能力（如果有需求）

2. API 与集成:
   - [ ] API 文档质量和 SDK 支持
   - [ ] 流式响应支持
   - [ ] Function Calling / Tool Use 支持
   - [ ] 结构化输出（JSON Mode）
   - [ ] 多模态支持（图片/音频/视频输入）

3. 服务可靠性:
   - [ ] SLA 承诺（可用性 >= 99.9%）
   - [ ] 速率限制说明
   - [ ] 有状态/无状态 API
   - [ ] 历史宕机记录

4. 安全性:
   - [ ] 数据传输加密（TLS 1.3）
   - [ ] 数据存储位置和策略
   - [ ] 是否用于模型训练
   - [ ] 安全认证（SOC 2 / ISO 27001 / GDPR）
   - [ ] 数据删除机制

5. 成本:
   - [ ] 完整的价格表（输入/输出/缓存/微调）
   - [ ] 批量折扣
   - [ ] 预留容量折扣
   - [ ] 免费额度

6. 支持:
   - [ ] 技术支持响应时间
   - [ ] 社区活跃度
   - [ ] 中文支持
   - [ ] 文档和示例质量
```

## 六、最终建议

```
场景-供应商映射：

快速原型 / MVP:
  → GPT-4o-mini 或 DeepSeek-V3（便宜、好用）

中文企业应用:
  → DeepSeek-V3（主力）+ Qwen-Max（备用）
  → 或 GPT-4o（如果数据合规允许）

代码生成 / 技术场景:
  → Claude Sonnet 4（主力）+ GPT-4o（备用）

超长文档处理:
  → Gemini 2.5 Pro（1M context）

成本敏感 + 质量要求高:
  → DeepSeek-V3（性价比之王）

合规要求严格（数据不出境）:
  → DeepSeek（开源私有化）或 Qwen（开源私有化）

多供应商策略:
  → GPT-4o (主力) + DeepSeek-V3 (降级) + Claude Sonnet 4 (代码)
```
