# Track D：企业合规与商业

> **对应阶段**：Phase 09 - Phase 11
> **定位**：AI 的"商业面"——不仅是技术决策，更是商业和合规决策
> **前置要求**：Track A-C 的技术基础（理解 RAG 系统的成本结构和数据流）

---

## 课程地图

```
Track D：企业合规与商业 (2周)
│
├── D1：ROI 与商业决策 ────────────── Phase 09-10
│   ├── AI 功能 ROI 计算器（可运行的 .py）
│   ├── 自建 vs 平台 vs SaaS（3D 决策矩阵）
│   ├── 成本归属与计费（多租户计费模型）
│   └── 供应商评估框架（LLM 供应商评分卡）
│
└── D2：合规与治理 ────────────────── Phase 10-11
    ├── GDPR 与 AI（删除权、数据最小化、DPIA）
    ├── 中国数据安全法（PIPL、跨境传输、分类分级）
    ├── AI 治理框架（Model Card、影响评估、偏见测试）
    └── AI 伦理与负责任 AI（幻觉风险评估、透明度、碳核算）
```

## 产出物检查清单

完成 Track D 后，你应当能够：

- [ ] 用 ROI 计算器计算 AI 功能的投入产出比
- [ ] 在"自建 vs 平台 vs SaaS"之间做出理性决策
- [ ] 设计多租户计费和成本归属方案
- [ ] 评估 LLM 供应商并制定切换策略
- [ ] 判断你的系统是否符合 GDPR/PIPL 要求
- [ ] 为你的 AI 系统编写 Model Card
- [ ] 识别并缓解 AI 系统的幻觉风险
- [ ] 建立 AI 伦理审查流程
